How to read this. NLI scores show how well a sentence aligns with the claim, not the probability that it is true. The evidence score is a simple rule over the evidence found, not a calibrated confidence. Extracted relations are automatic and unreviewed. Analyst tools

Extracts the relationship claims in a new report and checks each one against the 104-report corpus: what is corroborated, what the corpus contradicts or disputes, and what is new intel. The report itself is not added to the corpus.
Pulls IP addresses, domains, URLs, e-mails, file hashes and CVEs out of report text, refanging hxxp / [.] first. Private IPs, file names and well-known reference sites are listed separately with the reason.
One claim per line, either APT28 | USES | Zebrocy (relations: USES, TARGETS, EXPLOITS, USES_TECHNIQUE; prefix NOT for a negative claim) or a question like Does APT29 use Cobalt Strike?. Up to 25 lines; a subject,relation,object CSV works too.
Finds the shortest chains of relations linking two entities in the knowledge graph, preferring specific links over generic hubs like “government”. Every hop shows its source sentence and whether the NLI verifier finds that the text states it.
Side-by-side view of what 2 or 3 actors or malware families share: malware and tools, targets, ATT&CK techniques and CVEs, each with the sentence and source behind it.
